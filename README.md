# fishing-swift

Rebuild the fishing game from **https://github.com/ridermw/fishing** (play it at https://ridermw.github.io/fishing/) using **Swift + RealityKit**.

Make it the same game: same world, mechanics and features. Generate all art and sound in code, with no image or audio files. The Rust port at https://github.com/ridermw/fishing-rs is a second reference.

Target visionOS and iOS, with the village as a tabletop diorama. Build and run it with Xcode.
